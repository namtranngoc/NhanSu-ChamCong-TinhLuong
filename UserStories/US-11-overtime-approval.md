# US-11 - Duyệt và từ chối tăng ca

## Epic

Overtime Management

## Actor

Manager

## User Story

As a manager, I want to approve or reject overtime requests, so that only approved overtime is included in payroll.

## Description

Manager kiểm tra và quyết định duyệt hoặc từ chối yêu cầu tăng ca của nhân viên.

## Acceptance Criteria

- [ ] Manager xem được danh sách yêu cầu tăng ca.
- [ ] Manager xem được chi tiết yêu cầu.
- [ ] Manager có thể duyệt yêu cầu.
- [ ] Manager có thể từ chối yêu cầu.
- [ ] Khi từ chối phải nhập lý do.
- [ ] Trạng thái chuyển thành APPROVED khi duyệt.
- [ ] Trạng thái chuyển thành REJECTED khi từ chối.
- [ ] Chỉ yêu cầu APPROVED được đưa vào tính lương.
