# US-08 - Gửi yêu cầu nghỉ phép

## Epic

Leave Management

## Actor

Employee

## User Story

As an employee, I want to submit a leave request, so that I can request time off from work.

## Description

Nhân viên gửi yêu cầu nghỉ phép và chờ quản lý phê duyệt.

## Acceptance Criteria

- [ ] Employee có thể tạo yêu cầu nghỉ phép.
- [ ] Employee chọn loại nghỉ.
- [ ] Employee chọn ngày bắt đầu.
- [ ] Employee chọn ngày kết thúc.
- [ ] Employee nhập lý do.
- [ ] Hệ thống tính số ngày nghỉ.
- [ ] Hệ thống kiểm tra số ngày phép còn lại.
- [ ] Yêu cầu mới có trạng thái PENDING.
- [ ] Employee xem được trạng thái yêu cầu.

High
