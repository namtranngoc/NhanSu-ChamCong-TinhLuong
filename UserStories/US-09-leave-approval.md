# US-09 - Duyệt và từ chối nghỉ phép

## Epic

Leave Management

## Actor

Manager

## User Story

As a manager, I want to approve or reject leave requests, so that employee leave can be managed.

## Description

Manager xem các yêu cầu nghỉ phép thuộc phạm vi quản lý và quyết định duyệt hoặc từ chối.

## Acceptance Criteria

- [ ] Manager xem được danh sách yêu cầu nghỉ phép.
- [ ] Manager xem được chi tiết yêu cầu.
- [ ] Manager có thể duyệt yêu cầu.
- [ ] Manager có thể từ chối yêu cầu.
- [ ] Khi từ chối phải nhập lý do.
- [ ] Trạng thái chuyển thành APPROVED khi duyệt.
- [ ] Trạng thái chuyển thành REJECTED khi từ chối.
- [ ] Employee xem được kết quả.
- [ ] Số ngày phép được cập nhật khi yêu cầu được duyệt.
